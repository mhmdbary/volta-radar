# تنبيهات VOLTA على تيليجرام

البوت بيراقب الحسابات الموجودة في `handles.txt`. أول ما حدا منهم ينشر تويتة جديدة، بيوصلك إشعار على تيليجرام فيه النص وزر **Open on X**.
البوت **ما بينشر ولا بيرد** على X نهائياً، والرد بتكتبه أنت بإيدك.

## 1) اعمل بوت تيليجرام (مجاني)
1. افتح تيليجرام وابحث عن **@BotFather**
2. ابعتله `/newbot` واختار اسم ويوزرنيم للبوت
3. بيعطيك **token**، احفظه

## 2) مفتاح قراءة تويتر
قراءة تويتات X ما عادت مجانية من X نفسها، عشان هيك منستخدم **twitterapi.io**:
1. سجّل في https://twitterapi.io
2. انسخ الـ **API Key** من الداشبورد
3. شيّك صفحة الأسعار. بيعطوا رصيد تجريبي عند التسجيل، وبعده التكلفة على حسب عدد التويتات اللي بتنقرأ (عادة قليلة لهذا الاستخدام)

## 3) الإعداد
```
copy config.example.json config.json
```
افتح `config.json` وحط فيه:
- `twitterapi_key`: المفتاح من الخطوة 2
- `telegram_bot_token`: التوكن من BotFather

بعدين افتح البوت تبعك في تيليجرام، اضغط **Start**، وشغّل:
```
python notifier.py --chat-id
```
انسخ الرقم اللي بيطلع وحطه في `telegram_chat_id`.

## 4) جيب قائمة الحسابات
```
python fetch_handles.py
```
هذا الأمر بيحفظ كل الحسابات اللي بيتابعها @VoltaFamily في `handles.txt`. وبتقدر تضيف أو تحذف يوزرات يدوياً (كل يوزر بسطر لحاله).

## 5) شغّل
```
python notifier.py
```
بيفحص كل 3 دقائق، وبتقدر تغيّر المدة من `poll_minutes`. خلّي النافذة مفتوحة.
للتجربة مرة وحدة بس:
```
python notifier.py --once
```

## نصائح للرد
- اكتب رد حقيقي له علاقة بالتويتة، مش نسخ ولصق
- ما ترد على كل تويتة. اختار اللي عندك فيها إشي مفيد تحكيه
- وضّح إنك مرتبط بـ Volta. هذا من قوانين X للترويج، وبيخلي الناس تثق فيك أكثر

## الإضافات
كل الإعدادات في `settings.json`:
- `mention_terms`: الكلمات اللي بتعمل تنبيه 💬 لما أي حدا يذكرها على X
- `highlight_words`: إذا التويتة فيها وحدة منهم بتنعلم ⭐ IMPORTANT
- `daily_hour_utc` و `launch_date`: وقت الملخص اليومي 📊 والعداد ⏳
- `watch_follows_of`: إذا هالحسابات تابعت حدا جديد بيوصل تنبيه 🆕
